## 배경 (디코 논의 요약, 26.7.30~31)

- 현재 방식: 문제 풀이도 배틀처럼 Elo 기반으로 레이팅이 실시간 갱신됨. 이 경우 난이도가 다른 두 문제를 어떤 순서로 푸느냐에 따라 최종 레이팅이 미세하게 달라지는 문제가 있음 (쉬운 문제 먼저 풀면 최종 레이팅이 아주 살짝 더 높게 나옴).
- Pacto7107(뤀카 아님, 협업자) 제안: 레이팅 계산 방식을 **"유저가 푼 문제들의 티어 점수 합"**으로 바꾸자.
  - **문제의 티어 점수** = 그 문제 티어를 숫자로 변환한 값. 예: `Origin III(or3) = 1`, `Apex I(ap1) = 6`
    - 즉 현재 `tier.js`의 티어 레벨 인덱스(0~17)에 그대로 +1 한 값과 동일 (레벨0=Origin III=1점, 레벨5=Apex I=6점 …)
  - 이렇게 하면 풀이 순서와 무관하게 레이팅이 결정됨 (합산이라 순서 의존성 사라짐)
